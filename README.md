# بنك أسئلة الاختيار من متعدد (MCQ Question Bank)

أسئلة اختبارية مستخرجة من ملفات PDF دراسية (مواد تحضير لاختبارات اللغة الإنجليزية
والأدب الإنجليزي للدراسات العليا)، جاهزة للاستخدام المباشر في أداة اختبارات إلكترونية.

## الملفات — 700 سؤال إجمالاً

| الملف | عدد الأسئلة | المصدر |
|---|---|---|
| `literature-bank-questions.js` | 215 | بنك أسئلة الأدب الإنجليزي (1000 سؤال وجواب): تاريخ الأدب، الشعر، المسرح، الرواية، المصطلحات الأدبية، النقد والنظرية |
| `grammar-questions.js` | 120 | كتاب "المغني في الاختبار الوطني الموحد": القواعد، الأفعال الناقصة، الشرط، الكلام المنقول، وظائف اللغة، مهارات المحادثة والاستيعاب |
| `reading-comprehension-questions.js` | 100 | قطع الاستيعاب المرشحة للاختبار الوطني (كل سؤال يذكر قطعته فيُفهم بذاته) |
| `dialogue-completion-questions.js` | 94 | كتاب Dialogue Completion (TEST 7) — حُوّلت من 5 اختيارات إلى 4 |
| `prepositions-questions.js` | 86 | فصل حروف الجر من English Grammar For All Levels (Sawalmeh) |
| `tenses-questions.js` | 45 | جداول الأزمنة الإنجليزية الاثني عشر (الصيغ، الاستخدامات، الدلالات الزمنية) |
| `uob-literature-questions.js` | 40 | أسئلة امتحان الأدب الإنجليزي المسترجعة — جامعة بغداد |

## صيغة الأسئلة

كل ملف يحتوي على مصفوفة JavaScript بهذا الشكل:

```js
const questions = [
  {
    id: "q001",                 // معرّف فريد لكل سؤال
    question: "نص السؤال",       // بالإنجليزية
    options: [                   // 4 اختيارات دائماً
      "الاختيار الأول",
      "الاختيار الثاني",
      "الاختيار الثالث",
      "الاختيار الرابع"
    ],
    correctIndex: 2              // رقم الاختيار الصحيح (يبدأ من 0)
  },
];
```

- `correctIndex` يبدأ من الصفر: `0` = الاختيار الأول، `3` = الاختيار الرابع.
- اختيار واحد فقط صحيح، والبقية مموّهات منطقية قريبة من الصواب.
- الأسئلة مزيج من أسئلة فهم وتحليل بمستوى دراسات عليا وأسئلة معلومات أساسية مباشرة.
- ملاحظة: ملف جامعة بغداد مصدره أسئلة مسترجعة من الذاكرة، وقد نُبّه في أصله إلى أن
  الإجابات ليست مؤكدة بالضرورة؛ نُقلت كما وردت.

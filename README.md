# بنك أسئلة الاختيار من متعدد (MCQ Question Bank)

بنك أسئلة أصلي بصياغة خاصة لاختبارات اللغة الإنجليزية والأدب الإنجليزي
(مستوى الدراسات العليا)، جاهز للاستخدام المباشر في أداة اختبارات إلكترونية.
الأسئلة تغطي معلومات ومفاهيم عامة متداولة في المناهج والمراجع الأكاديمية،
وصيغت جميعها صياغة مستقلة.

## المعاينة التفاعلية

`exam-preview.html` — صفحة اختبار كاملة تعمل بدون خادم: 100 سؤال عشوائي لكل
محاولة، مؤقّت 60 دقيقة مع تسليم تلقائي، درجة واحدة لكل سؤال (المجموع من 100)،
وإعادة الاختبار تعرض أسئلة مختلفة عن المحاولات السابقة حتى استنفاد البنك كاملاً.

## صيغة الأسئلة

كل ملف يحتوي على مصفوفة JavaScript بهذا الشكل:

```js
const questions = [
  {
    id: "q001",                 // معرّف فريد لكل سؤال
    question: "نص السؤال",       // بالإنجليزية
    options: [                   // 4 اختيارات دائماً
      "الاختيار الأول",
      "الاختيار الثاني",
      "الاختيار الثالث",
      "الاختيار الرابع"
    ],
    correctIndex: 2              // رقم الاختيار الصحيح (يبدأ من 0)
  },
];
```

- `correctIndex` يبدأ من الصفر: `0` = الاختيار الأول، `3` = الاختيار الرابع.
- اختيار واحد فقط صحيح، والبقية مموّهات منطقية قريبة من الصواب.
- الأسئلة مزيج من أسئلة فهم وتحليل بمستوى دراسات عليا وأسئلة معلومات أساسية مباشرة.
- أسماء الشخصيات الواردة في أمثلة الجُمل والمحادثات والقصص أسماء عامة
  لأغراض تعليمية ولا تشير إلى أشخاص حقيقيين.

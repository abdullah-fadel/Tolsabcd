# أداة الاختبارات الأكاديمية
### جزء من منصة مكتبة الإنجاز الإلكترونية

ثلاثة اختبارات مستقلة تماماً (اللغة العربية / اللغة الإنجليزية / الحاسوب) بمحرك عرض مشترك واحد — تعديل مادة يعني تعديل ملف بياناتها فقط.

| الخاصية | القيمة |
|---|---|
| عدد الأسئلة | 60 سؤالاً تُختار **عشوائياً من بنك كبير** لكل مادة |
| حجم البنوك | عربي 510 — إنجليزي 700 — حاسوب 567 سؤالاً |
| المدة | 60 دقيقة (عدّاد تنازلي، تسليم تلقائي عند الصفر، والسيرفر يرفض التسليم المتأخر) |
| الدرجة | 100 درجة موزعة عشوائياً على الأسئلة (المجموع 100 بالضبط) |
| العرض | 3 صفحات × 20 سؤالاً مع تنقّل دون فقدان الإجابات |
| النتيجة | الدرجة الكلية + التقييم + الأسئلة الخاطئة مع الحل الصحيح لكل واحدة |

## ⭐ إعادة الاختبار بأسئلة مختلفة
عند إنهاء الطالب للاختبار وإعادته، تظهر له **أسئلة مختلفة عن محاولاته السابقة**:

1. المتصفح يحفظ معرّفات الأسئلة التي ظهرت للطالب (localStorage — بدون أي إجابات).
2. عند بدء جلسة جديدة تُرسل هذه المعرّفات للسيرفر فيستبعدها من الاختيار العشوائي.
3. عندما لا يتبقى في البنك ما يكفي لاختبار كامل (بعد ~8 محاولات) يعيد السيرفر الدورة من كامل البنك ويُصفَّر السجل تلقائياً.

## هيكلة الملفات
```
exams-tool/
├── index.html            ← اختيار الاختبار (3 كروت)
├── exam.html             ← صفحة أداء الاختبار (مشتركة للثلاثة)
├── result.html           ← صفحة النتيجة النهائية
├── exam-engine.js        ← المنطق المشترك (توقيت، تنقل، جلسات، إعادة بأسئلة مختلفة)
├── exam-engine.css       ← الهوية البصرية (كحلي #0E2A47، ذهبي #D4AF37، كريمي #F6F1E7، RTL)
├── config.js             ← رابط الـ API (فارغ = نفس الأصل)
├── .assetsignore         ← يمنع نشر المجلدات السرية كملفات ثابتة
├── data/
│   └── manifest.json     ← بيانات وصفية فقط (عناوين ومدد) — لا توجد أي أسئلة
│                            في أي ملف يصل للمتصفح
├── server/               ← سري — لا يصل للمتصفح أبداً
│   ├── worker.js         ← Cloudflare Worker: /api/session و /api/questions و /api/grade
│   ├── exam-api.js       ← منطق الجلسات وتسليم الأسئلة المشفرة والتصحيح
│   ├── questions-data.js ← نصوص الأسئلة والخيارات (مولَّد — سيرفر فقط)
│   ├── answer-keys.js    ← الإجابات الصحيحة (مولَّد — سيرفر فقط)
│   ├── bank-index.js     ← معرّفات أسئلة كل بنك (مولَّد)
│   └── wrangler.toml
├── question-banks/       ← البنوك المصدرية بالإجابات (لا تُنشر أبداً)
└── tools/
    ├── build-data.mjs    ← يولّد data/ و answer-keys من البنوك
    └── dev-server.mjs    ← سيرفر تجربة محلي بنفس منطق الـ Worker
```

## التشغيل محلياً (للتجربة)
```bash
node exams-tool/tools/dev-server.mjs
# ثم افتح http://localhost:8788
```

## النشر على Cloudflare Workers
```bash
cd exams-tool/server
npx wrangler secret put EXAM_SECRET   # سر عشوائي طويل — مرة واحدة
npx wrangler deploy
```
الـ Worker يقدّم الواجهة والـ API معاً من نفس الرابط. ملف `.assetsignore` يضمن عدم نشر `server/` و`question-banks/` و`tools/` كملفات ثابتة.

عند ربط الأداة بنطاق المنصة فعّل تقييد الأصل في `wrangler.toml`:
```toml
[vars]
ALLOWED_ORIGINS = "https://your-domain.com"
```

## تعديل أو إضافة أسئلة
1. عدّل ملف المادة في `question-banks/` (الصيغة: `id`, `question`, `options` ×4, `correctIndex`).
2. أعد التوليد: `node exams-tool/tools/build-data.mjs`
3. أعد النشر.

## الحماية المطبَّقة (سرية بنك الأسئلة)
- **لا يوجد أي ملف أسئلة يصل للمتصفح**: بنوك الأسئلة كاملة (`questions-data.js`) والإجابات الصحيحة (`answer-keys.js`) تعيش داخل الـ Worker فقط. فتح `data/…` أو `server/…` من المتصفح يعطي 404/403.
- **تسليم عند الحاجة فقط**: الطالب يستلم 20 سؤالاً (صفحته الحالية) عبر `/api/questions` بجلسة موقّعة — لا يمكن طلب أسئلة بلا جلسة صالحة، ولا طلب صفحة خارج نطاق جلسته.
- **تشفير AES-GCM للحمولة**: نصوص الأسئلة تنتقل مشفرة بمفتاح مشتق من توكن الجلسة — تبويب Network في أدوات المطوّر يعرض نصاً مشفراً، لا أسئلة.
- **لا أثر في التخزين**: الأسئلة المفكوكة تعيش في ذاكرة JavaScript فقط — localStorage/sessionStorage لا يحتويان أي نص سؤال (معرّفات وتوكن فقط)، فتبويب Application فارغ منها.
- **التصحيح في السيرفر حصراً** — النتيجة تُحسب في الـ Worker، والحلول الصحيحة تُكشف فقط بعد التسليم وللأسئلة الخاطئة فقط (للمراجعة).
- **جلسة موقَّعة (HMAC-SHA256)**: التوكن يحدد الأسئلة والدرجات ووقت البداية/الانتهاء من ساعة السيرفر — أي تعديل يُرفض (401)، وأي تسليم متأخر يُرفض (403).
- **خلط عشوائي** لترتيب الأسئلة (بالسيرفر) وترتيب الخيارات (لكل جلسة) — يصعّب تبادل «الأجوبة الجاهزة».
- **كاشف أدوات المطوّر أثناء الاختبار**: فتح لوحة DevTools الملتصقة على الشاشات الكبيرة يحجب الأسئلة بطبقة تغطية حتى تُغلق (والمؤقّت مستمر).
- **رادع نسخ**: تعطيل يمين الفأرة والنسخ و`user-select` واختصارات DevTools الشائعة.
- **Rate limiting** في الـ Worker لكل IP + إمكانية تقييد `Origin`.

### حدود الحماية — بصراحة
- ما يُعرض على الشاشة يمكن دائماً تصويره أو نقله يدوياً — لا توجد تقنية متصفح تمنع ذلك 100%. الحماية أعلاه تمنع **سحب البنك كاملاً بسهولة** وتجعل جمعه يتطلب جلسات كثيرة متتابعة (كل جلسة 60 سؤالاً فقط) يعيقها الـ rate limiting.
- تشفير الحمولة يمنع القراءة من تبويب Network، لكن مفتاحه مشتق من توكن الجلسة نفسها — السرية الفعلية مصدرها أن البنك لا يغادر السيرفر أصلاً.
- المتطلب التقني: فك التشفير يحتاج HTTPS (متوفر تلقائياً على Workers) أو localhost للتطوير.

> ملاحظة معروفة: بدون نظام حسابات، سجل «الأسئلة المُشاهدة» (معرّفات فقط، بلا نصوص) محفوظ في متصفح الطالب؛ مسح بيانات المتصفح يعيد الدورة من البداية. عند إضافة حسابات مستخدمين للمنصة مستقبلاً يُنقل السجل والنتائج لقاعدة بيانات مرتبطة بحساب الطالب.
